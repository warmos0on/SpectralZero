# SpectralZero 创新点总结（向导师汇报）

## 一、一句话结论

在论文 SpectralZero（文本驱动的零样本高光谱图像分类）官方架构基础上，通过**类别平衡采样 + 逐波段 z-score 标准化 + 关闭动态融合**这一组数据预处理与采样优化，Indian Pines 零样本分类 OA 从 **80.88 → 86.64**（同口径 seed42，+5.76）；3 个随机种子均值从 **80.69 → 88.77**（**+8.08**），且逐分组方向一致，非挑最优结果。

## 四、创新点机理分析（逐项，含代码行号）

### 4.1 类别平衡采样（+4.40 OA / +5.37 AA，最大单一功臣）

**代码**：`main.py:63-75`（`WeightedRandomSampler`，权重 = 1/class_count，`replacement=True`）

**问题**：Indian Pines 训练集极不平衡。13 个 seen 类训练样本从 253（Woods）到 15（Oats / Grass-pasture-mowed / Alfalfa），最大类是最小类的 **17 倍**；`batch_size=256` 时一个 batch 基本被大头类塞满，小类样本经常整批不出现。

**机理**：
- 原协议 `shuffle=True` 均匀采样 → 每步梯度 ≈ 大类样本的梯度，小类拿不到有效更新，直接学不会。
- 这是 ZSL，训练要做"视觉-文本对齐"；小类若在训练中几乎不出现，模型学不到它的视觉↔文本映射 → 测试时该小类全被分错。
- 平衡采样让每类每 epoch 曝光次数相等（约 94 次/类），小类从"看不见"变成"正常训练"。

**实证（消融 F，3-seed）**：G3 84.76→93.71（Stone-Steel-Towers 43.7→66.3，Corn-mintill 89.1→96.7）；G5 78.92→90.23（Wheat 49.9→97.7）；G1 65.13→82.12（Hay-windrowed 43.5→72.5）。受益的全是训练样本少、原本被淹没的类。

**代价（诚实）**：G2 86.46→82.65、G4 88.16→76.76 略降（大类曝光减少 + 小类重复采样过拟合风险），总体净 +4.40。

### 4.2 关闭动态融合，回退固定 0.2 权重（+2.59 OA / +4.65 AA）

**代码**：`model_sz.py:219-251`（动态 `_dynamic_fuse` vs 固定 `(1-0.2)*spatial + 0.2*spectral`）

**机理（为什么"听起来合理"却净负）**：
1. **置信度 ≠ 正确性（核心缺陷）**：`_branch_reliability` 用 softmax 的 top1 confidence / margin / entropy 估计"分支多可信"，但高置信度只代表"分支自己确定"，不代表判断对。CLIP 空间分支是预训练的、在 HSI 上自信但常错；光谱分支是随机初始化 MLP、初期对所有类都不确定 → 动态权重把光谱分支压到下限 0.05，光谱信息从 20% 砍到 5%，光谱分支梯度被饿死，恶性循环。
2. **逐样本权重抖动**：每个样本融合权重不同，损失面每步都在变，优化目标不稳定。
3. **温度超参过敏感**：`fusion_temperature=0.07` 使 softmax 极尖锐，可靠性估计退化，只剩噪声。

**实证**：3-seed 开动态 86.18 → 关动态 88.77（−2.59 OA）；AA 提升更大（+4.65）说明被饿死的正是难类/小类的光谱线索。

**边界**：结论是"当前实现"下的结论（温度、先验强度、min_weight 可调），不证明该方向永远不行。

### 4.3 z-score × 平衡采样协同（+3.12 OA）

**代码**：`main.py:49-59`（逐波段 `(x−mean)/std`，统计量只来自 seen 训练像素，防泄漏）

**为什么 z-score 单独开反而负（−2.03）**：
1. 抹掉"整体亮度"线索：Indian 原始是 uint16、DN 955-9604，不同地物整体辐射水平也有判别力，z-score 把它抹平。
2. 破坏 CLIP 预训练视觉编码器的输入分布假设，浅层适配度下降。
3. std 很小的波段（吸收带）被等权重放大，噪声占比上升。

**为什么配平衡采样转正（协同 +3.12）**：
1. 平衡采样后小类被反复训练，模型易走"亮度捷径"；z-score 抹掉亮度捷径，逼模型学真正的光谱形状特征，这部分特征在 ZSL 测试（unseen 类）上更泛化。
2. 原始 DN 值域跨 1000 倍，未标准化时大数值波段主导梯度；z-score 后每个波段同尺度，模型学到"形状"而非"谁数值大"。
3. 单开 z-score 的负效应（丢亮度）在平衡采样下被抵消，正效应（尺度统一、优化平稳）被放大。

**边界（诚实）**：协同是 3-seed 经验观测；强依赖数据分布——LongKou 是 float32、范围 0-28，z-score 直接崩盘（OA 36.30），不可无脑推广。

### 4.4 unseen 负样本（−4.23 OA / −6.39 AA，排除）

**代码**：`pipeline.py:21-28`（训练传完整文本矩阵）+ `model_sz.py:257-259`（全类矩阵做 cross entropy，unseen 只当负类）

**机理（为什么是结构性错误）**：
1. **训练目标与测试目标自相矛盾**：测试时 `pipeline.py:35` 把列空间切成只留 unseen 文本（`text_projection = text_projection[seen_class:]`）——unseen 是测试时**唯一正类候选**；训练却教模型压低对 unseen 文本的相似度，等于"训练教它讨厌、测试要求它喜欢"。
2. **AA 比 OA 跌得更狠（−6.39）印证**：unseen 类被系统性压低，per-class 平均重挫。
3. 全类矩阵下 3 个 unseen 类占负类大头，seen 类之间反而竞争不足，seen 内部分辨力也受损。

**实证（消融 B，seed42）**：只开负样本 OA 77.50 / AA 58.72，单独用就是灾难；组合中 −4.23。已默认关闭。

## 六、代码改动清单（哪改了、改了什么）

| 文件 | 改动 | 说明 |
|------|------|------|
| model_sz.py | 光谱-空间双分支融合 | 新增动态融合 `_dynamic_fuse`（分支可靠性加权），可开关；关闭时回退论文固定权重融合公式 |
| main.py | 数据预处理与采样 | 逐波段 z-score 标准化（统计量只来自 seen 训练像素，防泄漏）+ WeightedRandomSampler 类别平衡采样，均可开关 |
| main.py | 训练协议 | unseen 类仅作负类（完整 seen+unseen 文本矩阵作类别空间），可开关；新增 epochs/checkpoints 命令行参数 |

| run_honest_eval.py | 评测协议（新增） | 固定最后 checkpoint、多 seed mean±std、per-class AA，杜绝挑最优的假提升 |
| config/Indian.json 等 | 开关与超参 | 四个消融开关 + spectral_ratio=0.2 等 |
